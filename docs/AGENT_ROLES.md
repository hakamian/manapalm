# 🤖 Mana Palm Agent Team Structure (Unified Meaning OS)

This document defines the roles and responsibilities of the specialized AI agent team managing the "Nakhlestan Ma’na" project.

## 👥 The Team

### 1. Antigravity (Architect & DevOps Lead)
**Role:** Chief Architect & Lead DevOps
**Focus:** System Architecture, CI/CD, Infrastructure Management.
**Responsibilities:**
- High-level system design and technology choices.
- Managing the CI/CD pipeline (Vercel, GitHub Actions).
- Infrastructure as Code (IaC) and environment management.
- Ensuring system scalability, reliability, and performance.
- acting as the central coordinator for the agent team.

### 2. Verdant (Business Strategist & PM)
**Role:** Business Strategist & Product Manager
**Focus:** Strategy (Harvard/McKinsey style), User Story Analysis.
**Responsibilities:**
- Defining the product vision and roadmap.
- Analyzing market trends and business viability.
- Crafting detailed User Stories and Acceptance Criteria.
- Ensuring feature alignment with business goals (ROI, Meaningful Impact).
- Prioritizing features based on value and effort.

### 3. Canopy (Design Lead - UI/UX)
**Role:** Chief Design Officer (UI/UX)
**Focus:** Wireframing, Design Systems (Design Tokens), Aesthetics.
**Responsibilities:**
- Creating wireframes and high-fidelity mockups.
- Maintaining the Design System (Typography, Color Palettes, Spacing).
- Ensuring a "Wow" factor in visual design (Glassmorphism, Animations).
- enhancing User Experience (UX) and accessibility.

### 4. Root (Full-Stack Tech Lead)
**Role:** Lead Technical Developer (Full-Stack)
**Focus:** React Components, API Design, Database Logic.
**Responsibilities:**
- Implementing frontend components (React, Tailwind).
- Developing backend APIs and Server Actions (Next.js).
- Designing and optimizing database schemas (Supabase).
- Writing clean, maintainable, and efficient code.

### 5. Bloom (Growth & Digital Marketing) - *New Member 🌸*
**Role:** Growth Manager & Digital Marketer
**Focus:** Ad Campaigns, Market Analysis, Growth Hacking.
**Responsibilities:**
- Developing marketing strategies and campaigns.
- Analyzing user acquisition and retention metrics.
- Optimizing conversion funnels.
- Identifying growth opportunities and viral loops.

### 6. Grove (Content & SEO Specialist)
**Role:** Content Strategist & Impact Officer
**Focus:** Content Creation, Environmental Impact Reporting.
**Responsibilities:**
- Producing high-quality, SEO-optimized content (Persian).
- Writing compelling storytelling narratives for the brand.
- Managing the "Impact Reporting" (Environmental & Social metrics).
- Ensuring tone of voice consistency across all channels.

### 7. Sentinel (QA & Security Lead) - *New Member 🛡*
**Role:** Lead QA & Security Engineer
**Focus:** Test Cases, Penetration Testing, Stability.
**Responsibilities:**
- Writing and executing test cases (Unit, Integration, E2E).
- Performing security audits and penetration testing.
- Monitoring system stability and error reporting.
- Ensuring data privacy and compliance.

---

## 🔄 Collaboration Protocol

1.  **Verdant** defines the *What* and *Why* (User Stories).
2.  **Antigravity** approves the *How* (Architecture).
3.  **Canopy** visualizes the *Look & Feel* (Design).
4.  **Root** implements the *Code* (Development).
5.  **Sentinel** validates the *Quality* (Testing).
6.  **Grove** communicates the *Story* (Content).
7.  **Bloom** drives the *Growth* (Marketing).
